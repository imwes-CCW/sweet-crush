# 糖果繽紛樂 Sweet Crush（單機版三消）

一個用純 HTML / CSS / JavaScript 寫成的單機三消遊戲，機制參考 Candy Crush，
**不使用任何官方名稱、美術或音效**（那些屬於 King 公司的版權／商標）：
畫面以 emoji + CSS 自製，音效以 **Web Audio 即時合成**（無任何音檔）。
課金部分改成「**密碼模式**」：輸入密碼即可解鎖。

## 怎麼玩
直接用瀏覽器（Chrome / Edge / Firefox）打開 `index.html` 即可，**免安裝、免伺服器、可離線**。

## 操作
- **拖曳**或**點兩下**相鄰糖果交換位置，湊滿 3 顆同色即可消除。
- 消 **4 顆一線** → 條紋糖（清整行或整列）。
- 消 **L／T 形** → 包裝糖（炸 3×3）。
- 消 **5 顆一線** → 彩色炸彈（清除全場同色）。
- 兩顆特殊糖**互相交換**會觸發更強的組合技：
  - 條紋＋條紋＝十字清除
  - 條紋＋包裝＝三行三列大十字
  - 包裝＋包裝＝5×5 大爆炸
  - 彩色炸彈＋一般糖＝清除該色全部
  - 彩色炸彈＋條紋／包裝＝該色全部變強再引爆
  - 彩色炸彈＋彩色炸彈＝清空全場
- 關卡類型：🎯 分數關（步數內達標）、🟦 果凍關（清光所有果凍格）、🌰 食材關（把食材掉到底部、收集指定數量）。
- 障礙物：🧊 糖霜（消除相鄰糖果可破一層）、🕳️ 造型棋盤（corners／octagon／cross／diamond 等空洞形狀）。
- 道具：🔨 鎚子（敲掉一顆）、🔀 重洗、➕ 加 5 步。
- 🔊 音效：右上角／首頁可切換靜音（狀態會記住）。

## 關卡與難度設計
共 **400 關**，每 25 關設一個「👑 關主關」。三種關卡類型以約 12 關為一輪交錯出現（果凍第 4 關、食材第 12 關後登場），保持節奏新鮮。

**難度曲線（分數關）** —— 重點在「每一步需要打出多少分」，而非單純把目標數字灌大：

| 區段 | 每步需求分數 | 設計意圖 |
|------|------|------|
| 第 1 → 50 關 | 130 平滑爬升到 **800** | 由淺入深，學會佈局特殊糖 |
| 第 51 → 200 關 | 在 **600 ~ 1000** 間逐關波動 | 維持挑戰但永遠可達，難度有起伏不單調 |
| 第 201 → 400 關（專家區）| **1200 ~ 1500** | 硬牆，需頻繁打出特殊糖／組合技；靠道具與密碼禮包當燃料 |

> 一般每步可達分數約 500~800、用特殊糖組合可衝更高。前 200 關刻意壓在可達範圍內，**不會出現數學上無解的關卡**；201 關後是給高手的挑戰牆。

**障礙關分數減免**：分數關只要有 🧊 糖霜或 🕳️ 造型棋盤，每步需求會**壓到 600~800**（雙重或多層障礙再往 600 降）——讓難度由「障礙」承擔，而非分數與障礙雙重夾殺。

**障礙物採「間隔出現」**：糖霜（第 15 關起）與造型棋盤（第 30 關起）解鎖後並非每關都有，而是交錯登場、刻意保留乾淨棋盤；201 關後障礙會多層化（果凍／糖霜 2~3 層）。

**👑 關主關隨機**：每 25 關的關主關**每次挑戰都會重骰**目標（高分／果凍／食材）與障礙組合，進場才揭曉，增加變化與重玩性。

## 密碼模式（取代課金）
首頁 / 地圖 / 遊戲中按 🔑 開啟，大小寫皆可：

| 密碼 | 效果 |
|------|------|
| `SWEET31` | +3000 金幣 |
| `SWEET52` | +5000 金幣 |
| `SWEET99` | +10000 金幣 |
| `BOOST15` | 鎚子 / 重洗 / 加步數 各 +5 |
| `LIFE73` | 解鎖無限生命 |
| `RICH64` | 解鎖無限金幣 |
| `UNLOCK39` | 解鎖全部關卡 |
| `PREMIUM56` / `NOADS56` | 去廣告＋解鎖全部付費內容（道具無限） |
| `MOVES48` | 遊戲中當前關卡 +5 步 |
| `MASTER91` | 大師密碼：一次解鎖以上全部 |

### 🎁 一次性密碼（每帳號限用一次）
| 密碼 | 效果 |
|------|------|
| `WELCOME` | 道具各 +30 |
| `SWEET200` | 道具各 +50 |
| `STARTER` | +50000 金幣 |
| `GIFT888` | +88888 金幣 |

進度、金幣、生命、已兌換密碼都存在瀏覽器 `localStorage`，關掉再開仍保留。
（一次性密碼用過後會記錄在存檔，再輸入會提示「已使用過」。）

## 檔案結構
```
index.html        頁面結構
css/style.css     視覺與動畫
js/engine.js      三消核心引擎（配對 / 特殊糖 / 連鎖 / 重力）
js/data.js        關卡（400 關）、密碼表、存檔
js/audio.js       Web Audio 合成音效（消除升音 / 特殊糖 / 組合技 / 勝負 / 道具）
js/game.js        單關流程（步數 / 目標 / 勝負 / 關主隨機）
js/ui.js          渲染 / 輸入 / 動畫 / 彈窗 / 商店 / 密碼 / 音效掛點
js/main.js        啟動
```
