# 糖果繽紛樂 Sweet Crush（單機版三消）

一個用純 HTML / CSS / JavaScript 寫成的單機三消遊戲，機制參考 Candy Crush，
**不使用任何官方名稱、美術或音效**（那些屬於 King 公司的版權／商標），
所有素材以 emoji + CSS 自製。課金部分改成「**密碼模式**」：輸入密碼即可解鎖。

## 怎麼玩
直接用瀏覽器（Chrome / Edge / Firefox）打開 `index.html` 即可，**免安裝、免伺服器、可離線**。

## 操作
- **拖曳**或**點兩下**相鄰糖果交換位置，湊滿 3 顆同色即可消除。
- 消 **4 顆一線** → 條紋糖（清整行或整列）。
- 消 **L／T 形** → 包裝糖（炸 3×3）。
- 消 **5 顆一線** → 彩色炸彈（清除全場同色）。
- 兩顆特殊糖**互相交換**會觸發更強的組合技：
  - 條紋＋條紋＝十字清除
  - 條紋＋包裝＝三行三列大十字
  - 包裝＋包裝＝5×5 大爆炸
  - 彩色炸彈＋一般糖＝清除該色全部
  - 彩色炸彈＋條紋／包裝＝該色全部變強再引爆
  - 彩色炸彈＋彩色炸彈＝清空全場
- 關卡類型：🎯 分數關（步數內達標）、🟦 果凍關（清光所有果凍格）。
- 道具：🔨 鎚子（敲掉一顆）、🔀 重洗、➕ 加 5 步。

## 密碼模式（取代課金）
首頁 / 地圖 / 遊戲中按 🔑 開啟，大小寫皆可：

| 密碼 | 效果 |
|------|------|
| `SWEET` | +500 金幣 |
| `CANDY1000` | +1000 金幣（限用一次） |
| `BOOST` | 鎚子 / 重洗 / 加步數 各 +5 |
| `LIFE` | 解鎖無限生命 |
| `RICH` | 解鎖無限金幣 |
| `UNLOCK` | 解鎖全部關卡 |
| `PREMIUM` / `NOADS` | 去廣告＋解鎖全部付費內容（道具無限） |
| `MOVES` | 遊戲中當前關卡 +5 步 |
| `MASTER` | 大師密碼：一次解鎖以上全部 |

進度、金幣、生命、已兌換密碼都存在瀏覽器 `localStorage`，關掉再開仍保留。

## 檔案結構
```
index.html        頁面結構
css/style.css     視覺與動畫
js/engine.js      三消核心引擎（配對 / 特殊糖 / 連鎖 / 重力）
js/data.js        關卡、密碼表、存檔
js/game.js        單關流程（步數 / 目標 / 勝負）
js/ui.js          渲染 / 輸入 / 動畫 / 彈窗 / 商店 / 密碼介面
js/main.js        啟動
```
